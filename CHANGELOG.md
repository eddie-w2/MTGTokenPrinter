# Token Printer: what's new

Each "## version" section becomes the release notes shown in the app's update pop-up. Keep it short and plain.
Newest version first.

## 0.8.00
- Token Printer can now update itself. The first time you open it each day it checks for a new version, and Settings > App updates lets you check by hand or install an update you put off.
- Dark mode switch in Settings > Appearance.
- Help: a FAQ in Settings and a welcome guide the first time you open the app.
- Line spacing in the print screen is now even and goes much tighter (down to 0.4), with a Reset button.
- The version number in Settings now always matches the installed version.

## 0.7.04
- Dark mode switch, FAQ and welcome guide, tighter and more even line spacing, correct version number in Settings.
